# Employee Management System

I wanted to build something practical while learning TypeScript, instead of just learning concepts without actually using them.

So... I built an Employee Management System to understand how a frontend and backend work together, how APIs handle data and how to manage state in React.

### What's implemented?

- CRUD operations to create, view, update and delete employees
- Search employees by name and department
- Filter employees by active or inactive status
- Sort employees alphabetically and by salary
- Sync search and status filters with URL query parameters
- REST APIs using Express and TypeScript
- MongoDB integration using Mongoose
- React frontend connected to the backend using Axios

### Tech Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Backend:** Node.js, Express, TypeScript
- **Database:** MongoDB with Mongoose

The project has two main folders: `frontend` and `backend`, each with its own README.
