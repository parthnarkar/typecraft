# Backend

The backend of the Employee Management System, built using Node.js, Express, TypeScript and MongoDB.

This is where I handle the API routes, employee data and database operations while learning how to structure a TypeScript backend.

### What's implemented?

- REST APIs to create, fetch, update and delete employees
- MongoDB integration using Mongoose
- Search employees by name and department
- Filter employees by active or inactive status
- Use query parameters to filter employee records
- Handle errors and return appropriate HTTP responses

### Tech Stack

- Node.js
- Express
- TypeScript
- MongoDB
- Mongoose

### Run locally

```bash
npm install
npm run dev
```

Make sure MongoDB is running and the required environment variables are configured before starting the server.
